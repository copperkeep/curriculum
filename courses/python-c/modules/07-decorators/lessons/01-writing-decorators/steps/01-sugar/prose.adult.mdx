```python
@logged
def add(a, b): ...
```

means exactly `add = logged(add)`. A decorator is any callable that takes a
function and returns what should replace it — usually a wrapper closure:

```python
import functools

def logged(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        print("calling", func.__name__)
        return func(*args, **kwargs)
    return wrapper
```

`*args, **kwargs` lets the wrapper accept whatever the original did. `wraps`
copies the name and docstring across so the wrapped function still looks like
itself. Forgetting to `return` the result is the classic bug.
