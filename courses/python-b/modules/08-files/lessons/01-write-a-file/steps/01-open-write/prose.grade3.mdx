Boxes are lost when a program ends. Files are not. They stay saved.

`open(path, "w")` opens a file to write in it. `f.write(text)` puts text in. It does
not start a new line for you, so add one yourself. Always use a `with` line. It
shuts the file when you are done.

Here, files live inside your web page. But the code is the same as on a real
computer.
