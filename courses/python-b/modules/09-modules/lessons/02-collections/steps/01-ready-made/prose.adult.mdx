The tally and group-by patterns from the dictionaries module are common enough to
be in the standard library:

```python
from collections import Counter, defaultdict
Counter("banana")            # Counter({'a': 3, 'n': 2, 'b': 1})
Counter(words).most_common(3)

groups = defaultdict(list)   # missing keys start as []
groups[len(w)].append(w)
```

`deque` is a list optimised for adding and removing at both ends — use it for
queues instead of `list.pop(0)`.
