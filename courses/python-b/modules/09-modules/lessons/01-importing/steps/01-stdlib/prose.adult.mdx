Python ships with a large standard library. `import math` loads a module; use its
contents with a dot: `math.sqrt(16)`, `math.pi`.

`from math import sqrt, pi` pulls names in directly. `import statistics as st`
renames. Avoid `from module import *` — it hides where names came from.

A few you will use constantly: `math`, `random`, `statistics`, `string`,
`datetime`, `collections`, `itertools`, `json`, `csv`, `re`.
