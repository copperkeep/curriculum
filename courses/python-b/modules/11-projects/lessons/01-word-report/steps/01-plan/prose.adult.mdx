You will build a function that takes some text and returns a formatted report of
its most common words. Break it into functions, each testable alone:

1. `clean(text)` — lower-case, punctuation removed, split into words
2. `count(words)` — word -> count
3. `report(text, n)` — the top `n` lines, aligned

Small functions with clear inputs and outputs are what make a program debuggable.
