When a program is wrong, do not change things at random. Instead:

1. **Reproduce** it with the smallest input that fails.
2. **Predict** what each variable should hold at each step.
3. **Observe** what it actually holds — `print(f"{x=}")` at the suspect spot.
4. The first place prediction and observation disagree is the bug.

Explaining the code line by line, out loud, to anyone — or anything — finds a
surprising number of bugs on its own.
