When code breaks, Python shows an error. Read the last line first. It says what
kind of error it is, and what went wrong.

A `NameError` means a name is spelled wrong. A `TypeError` means the wrong kind of
value, like text plus a number. A `ValueError` means the right kind, but a bad value.
An `IndexError` means a spot that is not there. A `SyntaxError` means a typo, like a
missing colon.
